## NAV Alignment Method

Daily SEC NAV observations are loaded from the normalized local cache, filtered to selected fund `proj_id` columns, then resampled and aligned across the complete cache at month-end. If the final cache resampling label falls after the latest observed NAV date, that final label is capped to the latest observed date. The engine then slices the aligned panel to the requested date range; an earlier requested end date does not independently create or cap a partial month-end row.

## Cashflow Method

Recurring `contribution` cashflows of 2,000.00 are applied `monthly` at `end` of period.

## Rebalancing Method

Portfolio holdings are rebalanced to target weights using `monthly` schedule when the rebalance rule is due.

## Formula Reference

| formula | equation | variables | used_for |
| --- | --- | --- | --- |
| simple_returns | r_t = NAV_t / NAV_{t-1} - 1 | NAV_t = SEC NAV per unit at period t; r_t = period return | Fund returns, benchmark returns, monthly returns |
| time_weighted_return | TWRR = product_{t=1..n}(1 + r_t) - 1 | r_t = portfolio period return after return path construction; n = observed periods | Total portfolio return and benchmark excess return |
| annualized_return | R_ann = product_{t=1..n}(1 + r_t)^(m / n) - 1 | m = periods per year: 12 for month-end data, 252 for daily (business-day) data | TWRR CAGR, benchmark CAGR, CAPM alpha input |
| money_weighted_return | solve for r: sum_i(CF_i / (1 + r)^t_i) = 0 | CF_i = investor-perspective cashflow at nominal elapsed year t_i (initial outlay, each contribution/withdrawal, terminal value) | IRR (money-weighted return) -- diverges from TWRR CAGR when flow timing affects the investor's realised return |
| annualized_volatility | sigma_ann = std(r_t, ddof=1) * sqrt(m) | std(..., ddof=1) = unbiased sample standard deviation, the same convention as the cov/var behind beta | Volatility and Sharpe denominator |
| max_drawdown | DD_t = V_t / max(V_0,...,V_t) - 1; MDD = min(DD_t) | V_t = simulated portfolio value at period t | Maximum drawdown and repeat-drawdown stress scenario |
| beta_alpha | beta = cov(R_p, R_b) / var(R_b); alpha = R_p,ann - [R_f + beta * (R_b,ann - R_f)] | R_p = portfolio returns; R_b = benchmark returns; R_f = annual risk-free rate | Benchmark Risk tab: beta and CAPM-style alpha |

Additional report ratios: `Sharpe = (R_ann - R_f) / sigma_ann`, `Sortino = (R_ann - R_f) / sigma_down` where `sigma_down = sqrt(mean(min(r_t - MAR, 0)^2)) * sqrt(m)` with `MAR = 0`, `Calmar = R_ann / |MDD|`, `VaR_c = max(0, -percentile(r_t, (1 - c) * 100))` (historical, non-parametric), `tracking_error = std(R_p - R_b, ddof=1) * sqrt(m)`, and `information_ratio = (R_p,ann - R_b,ann) / tracking_error`.

See `docs/formula-reference.md` for the expanded methodology notes.

## Limitations

This is historical portfolio backtesting from SEC mutual-fund NAV data. It is not a forecast, investment recommendation, tax model, personal suitability assessment, or broker execution simulator. Corporate actions and dividend effects are reflected only to the extent they are embedded in SEC fund NAV.
